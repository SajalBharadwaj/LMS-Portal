# 🎓 Apex University — Enterprise LMS & Campus ERP Portal

A complete, production-grade **University Learning Management System (LMS) & Campus ERP Portal** built with **Next.js 14+ (App Router)**, **Tailwind CSS**, **React Context API**, and **LocalStorage Persistence**.

---

## ✨ Highlights & Key Features

### 1. 👥 Multi-Role Enterprise System (Sticky Role Switcher)
- **Student View ("Aarav Sharma")**: B.Tech CSE (Sem 7). Access attendance shortfall risk calculator, official marksheet printing, timetable, fee payment challans, assignment submissions, club event passes, campus cinema short films, and assessments.
- **Faculty View ("Prof. Rajesh Verma")**: Attendance register with 1-click Present/Absent toggling, assignment grading desk, and internal marks editor.
- **Admin / Dean View ("Dr. Meera Sen")**: Real-time fee collection ledger (₹18.45 Cr expected), notice broadcaster, and campus infrastructure live occupancy inspector.

### 2. 🗺️ Interactive 3D Campus Tour & Vector Blueprint Map
- **120-Acre Autonomous Campus**: 8 connected complexes (LHC, Dept. of CSE, Apex GPU Compute Cluster, Central Library, Hostels, Sports Arena, Innovation Hub, Admin Block).
- **GPS Wayfinding & Walking Route Calculator**: Calculate walking distance (meters) and duration (mins) from Nilgiri Student Hostel.
- **360° Panoramic Virtual Video Tour**: Embedded video streams for each building.

### 3. 🤖 AI Campus Copilot Chatbot
- 24/7 Academic assistant that handles attendance shortfalls, lecture timetable schedules, pending fee receipts, exam notices, and technical subject tutoring (Raft Consensus, Docker, Kubernetes).

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Vanilla Tailwind CSS (Dark/Light mode support)
- **Icons**: Lucide React
- **Effects**: Canvas Confetti
- **State Management**: React Context API + LocalStorage persistence

## 🚀 Quick Start & Installation

```bash
# Clone the repository
git clone https://github.com/SajalBharadwaj/LMS-Portal.git

# Navigate into project directory
cd LMS-Portal

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the portal!
